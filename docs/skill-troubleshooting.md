# 故障定位

- CONFIG_REQUIRED / ENVIRONMENT_REQUIRED：按 checks 补齐缺项；环境损坏不回退全局 Python，不在 doctor 自动安装。实例 .env 优先于管理探针继承的同名变量；启动前清除其他实例的变量或用本地 .env 明确设置。
- LOGIN_REQUIRED / AUTH_REQUIRED：先查对应比特窗口绑定和实时 Cookie 来源。浏览器仍登录不能保证旧 Token 快照有效，不盲目要求重新扫码。
- LOCKED：另一 Agent、旧入口或遗留子进程可能持锁；核对实例和 process。不能凭 PID 数字强杀，也不能清空锁文件解除内核锁。
- STARTING_OR_UNRESPONSIVE / TIMEOUT：继续 status 查看心跳与业务阶段，查看本机脱敏日志；不循环启动。主循环卡住会让十五秒心跳过期。
- 图片失败：检查对应任务属于飞书下载、图片验证、闲鱼上传还是 IM 发送阶段。仅单张静态 PNG/JPEG，最多 10 MiB、2500 万像素；不转换或压缩以偷偷绕过限制。
- UNKNOWN：请求结果未知，需要人工核对平台和客户收件。不要修改数据库为 QUEUED，也不要替用户重发。
- 路由失败：必须直接引用原卡片、客户提醒或已关联的本人回复；不以 root_id、昵称或最近会话兜底。
- 升级失败：保留 backups 下准备资源、快照和失败副本。检查版本及队列后再处理，不恢复可能导致重复发送的旧数据库。

diagnose 不导出聊天正文和协议原文。必要时用户在本机查看日志，只摘录脱敏错误类型。真实探针会产生平台副作用，必须有明确测试目标，不能为排障向随机客户试发。
